## 🚀 Projeto em destaque

### 🍺 Bar System — sistema de comandas para um estabelecimento real
Projeto autoral desenvolvido do zero para um bar em funcionamento, responsável pelo gerenciamento de comandas, produtos e clientes.

**Funcionalidades**
- Abertura, acompanhamento e fechamento de comandas
- Cadastro e gerenciamento de produtos
- Cadastro de clientes
- Geração de QR Code Pix com o valor da comanda para pagamento

**Repositórios**
- Backend (Python, Flask, SQLAlchemy, PostgreSQL): [bar-system-backend](https://github.com/hi-giih/bar-system-backend)
- Frontend (React, TypeScript): [bar-system-web](https://github.com/hi-giih/bar-system-web)
